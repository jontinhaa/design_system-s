UI Components

Square, flat, blue

Zero radius everywhere. Buttons are solid blocks whose labels animate on hover; cards are flat grey or outlined black. The source CSS defines hover (and, for the form, disabled / error / success) states only: there are no :focus, :active or :disabled button styles, so none are shown.

One 1400px column

Everything sits in a 1400px container with 20px gutters; section rhythm comes from very tall paddings (184–250px). Because type and spacing are em-based on a fluid root, the whole layout scales with the viewport.

Motion & Interaction

Snappy, typographic motion

Default ease is suiSmooth — CustomEase(0.4, 0, 0.05, 1) at 0.58s. Text is split into letters or lines and rolled, shuffled or masked; CSS hovers run .375s on cubic-bezier(.51,0,.08,1). All demos below run the original scripts.

Icons

Small, square, single-colour

Inline SVGs sized by their class in em, so they scale with the fluid root. Most sit in a filled square (grey-700 or blue); arrows come in pairs so one can slide out while the other slides in. Social glyphs use currentColor.
