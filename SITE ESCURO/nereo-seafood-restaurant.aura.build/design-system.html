05 · Motion & Interaction

Slow, Deliberate

Everything is CSS transitions toggled by classes — no GSAP timelines are used. Durations run long (300ms–1.2s) to feel unhurried.

  • Hover · color, fillstransition-all / transition-colors duration-300 · cubic-bezier(0.4,0,0.2,1)
  • Outline CTA · logo · drawerduration-500 · drawer ease-in-out
  • Preloader fadetransition-opacity duration-700 · hidden after 1500ms
  • Scroll reveal1s cubic-bezier(0.2,0.8,0.2,1) · translateY(30px) → 0 · stagger 100ms
  • Testimonial crossfadeduration-1000 ease-in-out · rotates every 5s
  • Image zoom1.2s cubic-bezier(0.25,0.46,0.45,0.94) · scale(1.08)
  • Shimmer@keyframes shimmer 1.5s infinite · translateX(-100% → 200%)
