# Como rodar

Abrir o `index.html` direto mostra o site parado, sem animações. Para ver o site vivo, rode um comando no terminal, **dentro desta pasta**:

| Sistema | Comando |
|---|---|
| Mac / Linux | `python3 serve.py --open` |
| Windows | `py serve.py --open` (ou dê duplo clique em `abrir.bat`) |

O navegador abre sozinho. Deixe o terminal aberto enquanto navega; para encerrar, `Ctrl+C`.

**Abrir o terminal nesta pasta**

- **Mac:** abra o Terminal, digite `cd ` (com espaço), arraste esta pasta para a janela e aperte Enter.
- **Windows:** clique na barra de endereço do Explorador de Arquivos nesta pasta, digite `cmd` e aperte Enter.
- **Linux:** botão direito dentro da pasta → Abrir no terminal.

Precisa do Python 3.8 ou mais novo: Mac e Linux já vêm com ele (se o Mac pedir para instalar as ferramentas de desenvolvedor, aceite); no Windows, instale pelo python.org.
